CampoABLeitura

Usar seu lote documental

Importe JSON com rows ou CSV com cabeçalho do modelo. O lote fica só em memória e se perde ao recarregar; exporte JSON para retomar. Máximo 1MB, 1.000 registros e 50 colunas CSV. row_id é obrigatório e único. Fabricante/código ou atributos ausentes permanecem desconhecidos; não preenchemos lacunas por inferência. Códigos são texto e conservam zeros à esquerda. Posições/embalagem exigem inteiros positivos e passo usa ponto decimal. Não inclua dados pessoais, segredos ou dados de cliente em issues.
