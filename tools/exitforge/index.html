O QUE FOI EXTRAÍDO
Um recorte.
Limites visíveis.
Partimos do exemplo público Multi Source Aggregation. A combinação de objetos e a marcação são explícitas no código. Isso não é um conversor universal.
  • A entrada offline substitui as chamadas HTTP por respostas fornecidas.
  • O pacote também inclui leitura HTTP opcional: uma execução registrada recebeu dois objetos de APIs públicas do GitHub. São metadados de repositórios, sem significado financeiro.
  • Timeout resulta em estado desconhecido, sem relatório parcial.
  • Arrays e valores nulos são recusados; há diferença de comportamento em relação ao modelo de referência.
  • Não foram comparados tempos de execução com n8n ou com o transpiler.
  • Nenhum dado demonstrativo é receita, cliente ou economia comprovada.
