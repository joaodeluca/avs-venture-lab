Faça uma nova execução no seu computador

Descompacte o pacote V04, entre na pasta execution e escolha um diretório novo:

python3 covenant.py init --contract task-contract.json --source synthetic-source.json --workspace ./minha-faq
python3 covenant.py verify --workspace ./minha-faq
# Antes de produzir: REJECTED / FILE_ABSENT (exit 2)
python3 covenant.py produce --workspace ./minha-faq
python3 covenant.py verify --workspace ./minha-faq
# Com a entrega correta na janela: LOCAL_ARTIFACT_MATCH

produce é um exemplo determinístico, não um LLM. Você também pode dar o contrato, fonte e token sintéticos a um trabalhador separado e salvar somente seu JSON no arquivo esperado. Roteiro para trabalhador separado. Código recebido de outro agente precisa de revisão antes de qualquer execução.

O que esta conferência resolve

Recusa uma tarefa marcada como feita quando o arquivo está ausente, errado, antigo ou ligado a outra execução. A leitura é separada do recibo.

Ela não verifica um sistema remoto, autentica o produtor, prova a verdade da fonte ou o valor comercial. Contrato, referência e filesystem do operador são confiados localmente. A contraprova histórica de recibos continua válida. Não é sandbox contra processo malicioso nem autorização para pagamento.
