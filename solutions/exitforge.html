COM SEUS PRÓPRIOS ARQUIVOS

Um workspace para usar agora.

A triagem aponta bloqueios e perdas. A etapa seguinte aceita somente Set v3.4 literal, retenção explicitamente true/false e nomes simples. Mostra o plano, testa até 1.000 objetos e emite Python original; não executa n8n ou comprova equivalência.

A DECISÃO

Avaliar uma extração delimitada para código independente.

Sair do editor significa também decidir quem passa a cuidar de agenda, credenciais, tentativas e estado. Uma tradução de nós não preserva automaticamente esses serviços.

01

O que você traz

Um único export JSON n8n local, até 1 MiB. O recorte reconhece cadeias determinísticas pequenas; parâmetros desconhecidos exigem revisão.

02

O que você leva

Análise estrutural e, se elegível, plano offline, resultado local e Python stdin/stdout sem dependências externas. Código/plano contêm nomes de campos e valores literais: revise antes de compartilhar.

RECORTE ATUAL

Quando faz sentido

Útil para recortar atribuições literais independentes de rede/estado. A transformação recebe objetos JSON comuns; não reproduz envelopes n8n, serviços do runtime ou valores padrão omitidos. Exige confronto autorizado antes de migrar.

Antes de decidir

Não é conversor universal de n8n, Make ou Zapier. Sem OAuth, escrita externa, dashboard, scheduler, espera longa ou estado durável. O limite de nós não define equivalência.
